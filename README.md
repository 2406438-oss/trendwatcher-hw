### 1️⃣ СБОР ДАННЫХ

#### Реализация
Создан модуль `scraper.py`, который собирает события из следующих источников:

**Конкуренты и источники:**
- **Яндекс Практикум**: Sitemap.xml, Блог
- **Skillfactory**: Sitemap.xml, Блог
- **Hexlet**: Блог
- **Netology**: Sitemap.xml, Блог
- **GeekBrains**: Sitemap.xml, Блог

**Типы источников:**
- ✅ **Sitemap.xml** (4 источника) - парсинг структуры сайта
- ✅ **Блоги** (5 источников) - HTML-парсинг статей
- ⚠️ **RSS** - не используется (большинство источников не предоставляют)

#### Результаты первого запуска
```
Запуск 1:
- Собрано событий: XX
- Сохранено в Firebase: XX
- Дубликатов: 0

Запуск 2 (через 1 час):
- Собрано событий: XX
- Сохранено в Firebase: 0
- Дубликатов: XX
```

#### Механизм предотвращения дубликатов
- Каждое событие получает уникальный ID на основе `MD5(url + title)`
- При сохранении проверяется существование документа с таким ID
- Повторные запуски не создают дубликаты

### 2️⃣ ИИ-РАЗМЕТКА СОБЫТИЙ

#### Реализация
Создан модуль `ai_marker.py` с использованием **DeepSeek API** (модель `deepseek-chat`).

#### Критерии важности (1-5)

**5 - Критическое:**
- Запуск нового продукта/направления
- Крупные сделки, партнёрства, инвестиции
- Громкие новости в СМИ

**4 - Высокая важность:**
- Существенные обновления продукта
- Новые маркетинговые кампании
- Значимые вакансии

**3 - Средняя важность:**
- Обычные статьи в блоге о продукте
- Стандартные вакансии
- Анонсы вебинаров

**2 - Низкая важность:**
- Общие статьи без привязки к продукту
- Новости отрасли

**1 - Минимальная:**
- Офтоп, развлекательный контент
- Технический контент без бизнес-значения

#### Пример размеченного события

```json
{
  "competitor": "Яндекс Практикум",
  "title": "Запускаем новое направление: Machine Learning Engineer",
  "url": "https://practicum.yandex.ru/blog/ml-launch",
  "importance": 5,
  "gist": "Яндекс Практикум запустил новый курс для ML-инженеров с гарантией трудоустройства и стажировкой в Яндексе",
  "why": "Запуск нового продуктового направления - критическое событие. Усиление конкуренции за студентов в нише ML/AI, прямая угроза нашим курсам."
}
```

#### Стоимость разметки

**Модель:** DeepSeek Chat
- Цена за 1M входящих токенов: $0.14
- Цена за 1M исходящих токенов: $0.28

**Результаты:**
- Среднее количество токенов на событие: ~500-800
- Средняя стоимость на событие: ~$0.0001-0.0002
- Стоимость разметки 50 событий: ~$0.005-0.010
- **Оценка на месяц (ежедневно 50 событий):** ~$0.15-0.30

**Преимущество DeepSeek:** В 5-10 раз дешевле GPT-4o-mini при сопоставимом качестве.

### 4️⃣ ОБОСНОВАНИЕ ПОРОГА ВАЖНОСТИ

**Выбранный порог:** 3 (средняя и выше)

#### Обоснование:
1. **События с важностью 3-5** содержат действительно релевантную информацию о действиях конкурентов
2. **События с важностью 1-2** - это в основном общие статьи и технический контент, не требующий немедленного внимания
3. Порог 3 обеспечивает баланс между полнотой и signal-to-noise ratio

#### Статистика по порогам:

## 🚀 ИНСТРУКЦИЯ ПО ЗАПУСКУ

### Предварительные требования
- Python 3.9+
- Firebase проект (см. SETUP_FIREBASE.md)
- DeepSeek API ключ
- Telegram бот

### Установка

1. Клонируйте репозиторий:
```bash
git clone <your-repo>
cd trendwatcher-hw
```

2. Создайте виртуальное окружение:
```bash
python -m venv .venv
source .venv/bin/activate  # Linux/Mac
# или
.venv\Scripts\activate     # Windows
```

3. Установите зависимости:
```bash
pip install -r requirements.txt
```

4. Настройте Firebase (см. `SETUP_FIREBASE.md`)

5. Создайте `.env` файл:
```bash
cp .env.example .env
# Заполните реальные данные
```

### Запуск

**Полный цикл (сбор → разметка → сводка → отправка):**
```bash
python main.py
```

**Только сбор:**
```bash
python scraper.py
```

**Только разметка:**
```bash
python ai_marker.py
```

**Тест Firebase подключения:**
```bash
python firebase_manager.py
```
