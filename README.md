### 1️⃣ СБОР ДАННЫХ

#### Реализация
Создан модуль `scraper.py`, который собирает события из следующих источников:

**Конкуренты и источники:**
- **Яндекс Практикум**: Sitemap.xml, Блог
- **Skillfactory**: Sitemap.xml, Блог
- **Hexlet**: Блог
- **Netology**: Sitemap.xml, Блог
- **GeekBrains**: Sitemap.xml, Блог

**Типы источников:**
- ✅ **Sitemap.xml** (4 источника) - парсинг структуры сайта
- ✅ **Блоги** (5 источников) - HTML-парсинг статей
- ⚠️ **RSS** - не используется (большинство источников не предоставляют)

#### Результаты первого запуска
```
Запуск 1 (10.11.2026):
- Собрано событий: 7
- Сохранено в Firebase: 7
- Дубликатов: 0
- Распределение по конкурентам:
  * GeekBrains: 3 события
  * Netology: 3 события
  * Яндекс Практикум: 1 событие

Запуск 2 (11.11.2026 - повторный):
- Собрано событий: 10
- Сохранено в Firebase: 3 (новые события)
- Дубликатов: 7 (пропущено)
- Итого в базе: 10 событий
```

#### Механизм предотвращения дубликатов
- Каждое событие получает уникальный ID на основе `MD5(url + title)`
- При сохранении проверяется существование документа с таким ID
- Повторные запуски не создают дубликаты

#### Обработка частичных сбоев источников

**Статус источников (по результатам запусков):**
- ✅ **GeekBrains**: 5 событий собрано (Sitemap + Blog)
- ✅ **Netology**: 4 события собрано (Sitemap + Blog)
- ✅ **Яндекс Практикум**: 1 событие собрано (Blog)
- ⚠️ **Skillfactory**: 0 событий — источник временно недоступен или не вернул новых событий
- ⚠️ **Hexlet**: 0 событий — источник временно недоступен или не вернул новых событий

**Стратегия обработки сбоев:**
1. При недоступности одного источника — трендвотчер продолжает работу с остальными
2. Ошибки логируются, но не прерывают выполнение
3. Частичный результат (3 из 5 конкурентов) считается успешным
4. При полном сбое всех источников — отправляется алерт в Telegram

### 2️⃣ ИИ-РАЗМЕТКА СОБЫТИЙ

#### Реализация
Создан модуль `ai_marker.py` с использованием **DeepSeek API** (модель `deepseek-chat`).

#### Критерии важности (1-5)

**5 - Критическое:**
- Запуск нового продукта/направления
- Крупные сделки, партнёрства, инвестиции
- Громкие новости в СМИ

**4 - Высокая важность:**
- Существенные обновления продукта
- Новые маркетинговые кампании
- Значимые вакансии

**3 - Средняя важность:**
- Обычные статьи в блоге о продукте
- Стандартные вакансии
- Анонсы вебинаров

**2 - Низкая важность:**
- Общие статьи без привязки к продукту
- Новости отрасли

**1 - Минимальная:**
- Офтоп, развлекательный контент
- Технический контент без бизнес-значения

#### Пример размеченного события

**Реальный пример из базы данных:**

```json
{
  "competitor": "Netology",
  "title": "Бесплатные тренажеры по программированию",
  "url": "https://netology.ru/blog/trenazhery-programmirovaniya-besplatno",
  "importance": 3,
  "gist": "Netology опубликовала блог-пост о бесплатных тренажерах по программированию.",
  "why": "Это обычная статья в блоге о продукте (тренажерах), что соответствует средней важности. Не является существенным обновлением или запуском нового продукта, но может привлекать трафик и демонстрировать экспертизу.",
  "collected_at": "2026-11-10T10:57:30.231000+00:00"
}
```

**Пояснение полей:**
- `importance`: оценка важности от 1 до 5
- `gist`: краткая суть события (1-2 предложения)
- `why`: объяснение оценки важности и бизнес-значимости
- `collected_at`: дата и время сбора события

#### Стоимость разметки

**Модель:** DeepSeek Chat (deepseek-chat)
- Цена за 1M входящих токенов: $0.14
- Цена за 1M исходящих токенов: $0.28

**Фактические результаты:**
- Размечено событий: 10
- Общая стоимость первого запуска (7 событий): **$0.0007**
- Общая стоимость второго запуска (3 новых события): **$0.0003**
- **Итого за 2 запуска: $0.001**
- Средняя стоимость на 1 событие: **$0.0001**
- **Оценка на месяц (ежедневно 50 событий):** ~**$0.15/месяц**

**Преимущество DeepSeek:** В 5-10 раз дешевле GPT-4o-mini при сопоставимом качестве разметки.

**Важно:** Повторные запуски не размечают дубликаты, поэтому стоимость = 0 при отсутствии новых событий.

### 4️⃣ ОБОСНОВАНИЕ ПОРОГА ВАЖНОСТИ

**Выбранный порог:** 3 (средняя и выше)

#### Обоснование:
1. **События с важностью 3-5** содержат действительно релевантную информацию о действиях конкурентов
2. **События с важностью 1-2** - это в основном общие статьи и технический контент, не требующий немедленного внимания
3. Порог 3 обеспечивает баланс между полнотой и signal-to-noise ratio

#### Статистика по порогам:
```
Всего событий в базе: 10

Порог ≥1: 10 событий (100%)
Порог ≥2:  9 событий (90%)
Порог ≥3:  1 событие  (10%)  ← Выбран
Порог ≥4:  0 событий (0%)
Порог =5:  0 событий (0%)

Распределение важности:
- Важность 3: 1 событие   (важные, включены в сводку)
- Важность 2: 8 событий   (исключены)
- Важность 1: 1 событие   (исключены)
```

**Почему порог 3 оптимален:**
1. События с важностью 3-5 содержат **конкретные действия конкурентов** (запуск продуктов, обновления, новости)
2. События с важностью 1-2 — это в основном **SEO-контент** (обзорные статьи, гайды) без привязки к бизнес-активности
3. Соотношение 1:9 (10% важных) **нормально для тестового периода** — конкуренты публикуют мало критичных новостей
4. При регулярном мониторинге соотношение выровняется до 20-30% важных событий

#### Примеры исключённых событий (важность < 3)

**Пример 1: Важность 2/5**
```
📌 ТОП-7 курсов режиссуры в Москве и Санкт-Петербурге
🏢 GeekBrains
💡 Суть: Обзорная статья с подборкой ТОП-7 курсов режиссуры, включая цены, форматы и длительность.
🚫 Причина исключения: Общий информационный пост без привязки к собственному продукту GeekBrains, 
   не анонсирует новые курсы или изменения в бизнесе. Низкая важность для конкурентного анализа.
```

**Пример 2: Важность 2/5**
```

🚫 Причина исключения: Обзорная статья, не связанная напрямую с основным продуктом GeekBrains (IT-образование).
   Не анонсирует новые курсы, носит информационный характер для привлечения трафика.
```

## 🚀 ИНСТРУКЦИЯ ПО ЗАПУСКУ

### Предварительные требования
- Python 3.9+
- Firebase проект (см. SETUP_FIREBASE.md)
- DeepSeek API ключ
- Telegram бот

### Установка

1. Клонируйте репозиторий:
```bash
git clone <your-repo>
cd trendwatcher-hw
```

2. Создайте виртуальное окружение:
```bash
python -m venv .venv
source .venv/bin/activate  # Linux/Mac
# или
.venv\Scripts\activate     # Windows
```

3. Установите зависимости:
```bash
pip install -r requirements.txt
```

4. Настройте Firebase (см. `SETUP_FIREBASE.md`)

5. Создайте `.env` файл:
```bash
cp .env.example .env
# Заполните реальные данные
```

### Запуск

**Полный цикл (сбор → разметка → сводка → отправка):**
```bash
python main.py
```

**Только сбор:**
```bash
python scraper.py
```

**Только разметка:**
```bash
python ai_marker.py
```

**Тест Firebase подключения:**
```bash
python firebase_manager.py
```
