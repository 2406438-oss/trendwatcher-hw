## 📋 Обязательные требования

### 1. Сбор данных
- [ ] Собирает события из 5 конкурентов
- [ ] Использует RSS/Sitemap/HTML источники
- [ ] Предотвращает дубликаты при повторном запуске
- [ ] Второй запуск НЕ создаёт дубликаты

### 2. ИИ-разметка
- [ ] Размечает события с полями: importance (1-5), gist, why
- [ ] Использует ИИ API (DeepSeek)
- [ ] Рассчитывает стоимость разметки на событие
- [ ] Рассчитывает стоимость на месяц (при ежедневном запуске)

### 3. Telegram сводка
- [ ] Формирует сводку с событиями ≥ порога важности
- [ ] Группирует по конкурентам
- [ ] Отправляет в Telegram
- [ ] Показывает метаданные (дата, ссылка, важность)

### 4. Обоснование порога
- [ ] Выбран порог важности (рекомендуется 3)
- [ ] Есть обоснование выбора порога
- [ ] Показаны исключённые события (< порога)
- [ ] Объяснено почему они исключены

### 5. Публичная витрина
- [ ] Развёрнута на GitHub Pages
- [ ] Показывает размеченные события
- [ ] Фильтрация по конкуренту
- [ ] Фильтрация по важности
- [ ] НЕ требует авторизации
- [ ] Использует публичный ключ (не server key)

### 6. Проверка доступа
- [ ] События читаются через публичный API
- [ ] События размечены (importance, gist, why)
- [ ] Поле raw НЕ доступно через публичный API
- [ ] Запись заблокирована через публичный API
- [ ] Публичная страница доступна

### 7. Отчёт (README.md)
- [ ] Раздел 1: Сбор данных (статистика, дубликаты)
- [ ] Раздел 2: ИИ-разметка (критерии, стоимость)
- [ ] Раздел 3: Telegram сводка (реальный текст)
- [ ] Раздел 4: Порог важности (обоснование, исключённые)
- [ ] Раздел 5: Публичная витрина (URL, скриншот)
- [ ] Раздел 6: Проверка доступа (вывод check_access.py)

# - @BotFather → /newbot
